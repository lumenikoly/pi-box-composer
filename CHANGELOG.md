# 0.0.5

pi-box-composer — Windows launcher для Pi в Podman или Docker Desktop.

- Мастер настройки движка, сервера llama.cpp и модели.
- Запуск Pi с доступом к проекту только для чтения или с записью.
- Новые сессии, продолжение и выбор прошлых сессий; недавние проекты.
- Отдельные конфигурации и история для Podman и Docker Desktop.
- Ограничение памяти при чтении вывода команд и обработке журнала.
- Ограниченный список моделей с быстрым удалением дубликатов и поддержкой отмены.

Релиз содержит исполняемый файл Windows x64 и SHA256SUMS. Для работы нужен
установленный Podman или Docker Desktop и доступный сервер llama.cpp.

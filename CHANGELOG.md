# 0.0.6

pi-box-composer — Windows launcher для Pi в Podman или Docker Desktop.

- Обновлён интерфейс: боковая панель проектов, поиск, закрепление папок, новые элементы управления и экраны настроек.
- Запись и bash настраиваются независимо: запретить, спрашивать или разрешить. Проекты могут наследовать общие значения или сохранять собственные.
- Добавлены общие правила доступа к файлам и командам и правила отдельных проектов.
- Добавлена команда «Открыть в pi» в меню папок Проводника; регистрацию можно отключить в настройках.
- Проект можно выбрать аргументом `--project` или позиционным путём, открыть напрямую через `--open`.
- Добавлены открытие папки истории и удаление сессий проекта с подтверждением, отдельно для каждого движка.
- В образ Pi добавлены ripgrep, fd-find и проверка доступности поисковых утилит.
- Обновлены README и скриншоты интерфейса.

Релиз содержит исполняемый файл Windows x64 и SHA256SUMS. Для работы нужен
установленный Podman или Docker Desktop и доступный сервер llama.cpp.

# 0.0.5

pi-box-composer — Windows launcher для Pi в Podman или Docker Desktop.

- Мастер настройки движка, сервера llama.cpp и модели.
- Запуск Pi с доступом к проекту только для чтения или с записью.
- Новые сессии, продолжение и выбор прошлых сессий; недавние проекты.
- Отдельные конфигурации и история для Podman и Docker Desktop.
- Отдельный образ Caddy без file capability для запуска прокси с `--cap-drop=all`.
- Ограничение памяти при чтении вывода команд и обработке журнала.
- Ограниченный список моделей с быстрым удалением дубликатов и поддержкой отмены.

Релиз содержит исполняемый файл Windows x64 и SHA256SUMS. Для работы нужен
установленный Podman или Docker Desktop и доступный сервер llama.cpp.
